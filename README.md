# JARVIS Surface

One unified Obsidian plugin to run every Claude session terminal-free: a
project/session board, a tailnet bearer-gated remote-control channel, and a
tap-don't-type ask-loop — consolidating session-modal, deborah-remote and
pocketoracle into a single thin-core plugin.

## Install (BRAT)

Beta install via [BRAT](https://github.com/TfTHacker/obsidian42-brat):
`BRAT → Add beta plugin → https://github.com/OrlandoOracle/jarvis-surface`,
then enable **JARVIS Surface** and set the device-local bearer under
*Settings → JARVIS Surface → Remote command channel*.

Source lives under `plugin/` (plugin) and `keystone/` (the Mini result-page
service). Root `manifest.json` / `main.js` / `styles.css` are the BRAT-facing
build artifacts.
